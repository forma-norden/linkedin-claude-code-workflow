# signal-loop-operator

## Purpose

Close the GTM loop across LinkedIn content, outbound performance, and retargeting data.

## Inputs Required

- campaign performance exports
- reply or pipeline outcome data
- current copy framework
- current scoring criteria

## Workflow

1. Compare outcomes by signal type and tier.
2. Detect winning message angles and weak sequence paths.
3. Propose scoring adjustments only when data supports change.
4. Update the copy framework changelog with winning variants.
5. Generate next-cycle action list for outbound and paid coordination.

## Output

- `signal-loop-review.md`
- `copy-framework-updates.md`
- `scoring-adjustment-proposals.md`

## Quality Gates

- no scoring change without supporting conversion evidence
- no copy update without tracked reply context
- no recommendation without explicit owner and due date
