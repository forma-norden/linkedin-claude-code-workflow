# The Claude Code LinkedIn Playbook
## The Execution Workflow Your GTM Stack Is Missing

*By Forma Nôrden - Updated March 2026*

> Most GTM teams treat LinkedIn as a broadcasting channel. Post content. Hope someone reaches out. Repeat.
>
> This playbook treats LinkedIn as what it actually is: a real-time database of buying signals. Every post you publish generates engagement data. Every engager is a named professional with a title, company, and email address. Every ad impression is targeting data you already own.
>
> Claude Code connects those signals to your outbound system automatically, at scale, without a team of SDRs manually copy-pasting between tools.

## Read this first

This resource is structured as a small page tree, not a single flat file.

Use it when you want one operating system for:

1. LinkedIn engagement capture and routing
2. LinkedIn ad campaign creation without living in campaign manager
3. End-to-end outbound execution from scored account list to live sequence
