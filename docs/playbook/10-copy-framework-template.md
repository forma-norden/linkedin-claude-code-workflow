# Copy Framework Template

> **Use this page when:** Claude Code needs the working outbound voice, structure, and sequencing logic for emails, LinkedIn messages, or ad copy.

## Voice and tone principles

These rules apply to every piece of copy generated from this framework:

- **Direct, not clever.** Say what you mean.
- **Specific, not vague.** Real outcomes beat broad claims.
- **Short sentences.** Cold outreach should stay tight.
- **One idea per email.** One problem, one solution, one ask.
- **No fluff openers.** Skip the generic pleasantries.
- **Signal-referenced where possible.** If a trigger exists, lead with it.

## Sequence 1: Signal-triggered (3 steps)

Use for Tier 1 and Tier 2 contacts when a specific signal has been identified.

### Email 1: Signal reference and single problem

**Subject lines:**

- `[Signal-specific]`
- `[Outcome-specific]`
- `[Direct]`

**Body:**

```text
[First name],

[Observed signal - one sentence.]

That usually means [the pain point this signal implies - one sentence.]

[What you do - one sentence, outcome-led.]

Worth 15 minutes this week?

[Your name]
[Title] - [Company]
```

### Email 2: Social proof

**Subject:** `Re: [Subject from Email 1]`

**Body:**

```text
[First name],

Didn't want to let this drop.

[Relevant proof point - one sentence.]

[Specific mechanism - one sentence.]

Happy to show you exactly how it's structured.

[Your name]
```

### Email 3: Low-friction close

**Subject:** `[First name] - last one`

**Body:**

```text
[First name],

Last note - don't want to clog your inbox.

[Restate the core problem in one sentence.]

If the timing's off, no problem. I'll leave the door open.

If it's relevant, here's a direct link to book 15 minutes: [calendar link]

[Your name]
```

## Sequence 2: ICP-fit automated (4 steps)

Use for Tier 3 contacts that fit the ICP but do not have an active trigger.

### Email 1: Problem-led cold open

**Subject lines:**

- `"[Company]'s outbound - quick thought"`
- `"[First name] - [specific pain point as question]"`
- `"LinkedIn -> pipeline - are you capturing it?"`

**Body:**

```text
[First name],

[One-sentence observation about a common ICP problem.]

[What you do - outcome-led, one sentence.]

[Social proof - one sentence.]

Worth a quick look?

[Your name]
[Title] - [Company]
```

### Email 2: Mechanism

**Subject:** `How it works`

**Body:**

```text
[First name],

Quick context on what we actually do:

-> [Mechanism step 1]
-> [Mechanism step 2]
-> [Mechanism step 3]

[Outcome sentence.]

Open to a 15-minute walkthrough?

[Your name]
```

### Email 3: Objection handle

**Subject:** `If the timing's wrong`

**Body:**

```text
[First name],

If you're already working on this internally, or the timing's off - understood.

If not, the reason most teams delay this is [common objection].

[One-sentence reframe.]

Still happy to talk if useful.

[Your name]
```

### Email 4: Final

**Subject:** `[First name] - closing this out`

**Body:**

```text
[First name],

Closing the loop here.

[One sentence value reminder.]

If it ever becomes relevant: [calendar link]

[Your name]
```

## LinkedIn ad copy framework

### Headline formula

`[Pain point or outcome] - [Mechanism or differentiator]`

Examples:

- `Your LinkedIn posts are generating leads. You're not capturing them.`
- `Signal-triggered outbound. No SDR team required.`
- `ICP list to live campaign in one Claude Code session.`

### Body copy formula

`[Who it's for] + [What it does] + [Specific outcome] + [CTA]`

### CTA options

1. `See how it works`
2. `Get the playbook`
3. `Book 15 minutes`
