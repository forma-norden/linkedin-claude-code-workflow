# Deployment Architecture

> **Best for:** individuals, small teams, and agencies deciding how to operationalize the workflows after the first successful run.

## For individuals and small teams

Run Claude Code locally and use Railway for autonomous weekly workflows.

The automation layer stays light, but the operating model still works.

## For teams who do not want to use a terminal

Use Claude Cowork as the handoff layer after the workflows are built.

That gives non-technical team members access to the same workflows through a visual desktop interface instead of terminal prompts.

## For agencies managing multiple clients

Maintain separate project folders per client.

Each client should have its own `CLAUDE.md`, scoring criteria, and copy framework, while a master architecture folder holds shared templates and skills.

One skill build can then benefit every client simultaneously.
