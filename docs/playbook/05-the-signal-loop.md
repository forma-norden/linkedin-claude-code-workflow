# The Signal Loop

> **Best for:** teams that want LinkedIn content, outbound execution, and retargeting to operate as one system instead of disconnected channels.

## Why this page matters

The three workflows in this playbook are not independent.

They form a closed loop where every output feeds the next input.

## The loop

```text
LinkedIn Post Published
        ↓
Engagers scraped, scored, and routed to outbound
        ↓
Tier 1 accounts -> full ABM campaign built
        ↓
Same account list -> uploaded to LinkedIn Ads as retargeting audience
        ↓
Decision-maker sees your ad and receives your email
        ↓
Reply data captured -> best-performing copy saved back into the framework
        ↓
Next campaign inherits what worked
```

## What compounds each cycle

| Asset | How it improves over time |
| --- | --- |
| [Copy Framework Template](10%20Copy%20Framework%20Template.md) | Winning subject lines, messaging angles, and objections get captured back into the source file |
| [ICP Scoring Criteria Template](09%20ICP%20Scoring%20Criteria%20Template.md) | Tier thresholds sharpen as scored predictions are compared against conversion data |
| [CLAUDE.md Starter Template](08%20CLAUDE%20Starter%20Template.md) | Tool rules, output standards, and execution safeguards stay consistent across workflows |

## Why this matters structurally

This is what separates a GTM system from a collection of outbound tools.

Each campaign improves the next one because the routing logic, scoring logic, and copy library all get stronger through use.

## The operating rule

Do not treat content, outbound, and retargeting as separate teams running separate motions.

Treat them as one signal system with different delivery channels.
